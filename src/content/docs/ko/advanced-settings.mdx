## 처음부터 고급 설정이 필요한가요?

보통 자동 탐색과 시스템 시간대만으로 충분합니다. 사용자 지정 로그 위치, 탐색되지 않는 CLI 또는 고정 보고 시간대가 필요할 때만 환경 변수를 변경하세요. 일상적인 화면 및 데스크톱 환경설정은 설정 메뉴에서 조정할 수 있습니다.

## 일상적인 동작 조정

- **테마 및 언어**: 밝은 모드 또는 어두운 모드와 인터페이스 언어를 선택하세요.
- **로그인 시 실행**: 컴퓨터에 로그인할 때 앱을 여세요.
- **자동 업데이트 확인**: 새 버전이 있는지 확인하세요.
- **메뉴 막대 / 시스템 트레이**: 표시할 한도 정보와 카운트다운 단위를 선택하세요.

메뉴 막대나 트레이 옵션을 변경한 뒤 읽기 편하고 원하는 구간이 표시되는지 확인하세요. 각 값의 의미는 [사용 한도](/ko/docs/quota/)를 참고하세요.

## 데이터 및 CLI 위치 선택

**`CODEX_HOME`**은 개별 JSONL 파일이 아닌 Codex 홈 디렉터리를 지정합니다. 비어 있지 않은 값은 기본값을 재정의하고 Windows/WSL 탐색을 비활성화합니다. 원하는 로그의 위치를 아는 경우에만 설정하세요.

**`CODEX_CLI_PATH`**는 `codex`, `codex.exe`, `codex.cmd` 같은 CLI 실행 파일이나 래퍼를 지정합니다. 자동 CLI 탐색이 실패하거나 사용자 지정 위치에 설치한 경우 사용하세요.

두 변수는 각각 로그를 읽는 위치와 사용할 CLI를 제어합니다. 앱을 실행하는 프로세스가 변수를 상속해야 합니다. 한 터미널에서 변수를 설정해도 바탕 화면 아이콘으로 실행한 앱에 전달된다는 보장은 없습니다.

## 보고 시간대 설정

**`CODEX_USAGE_TIMEZONE`**은 일별 그룹화를 제어합니다. 기본값은 시스템 시간대이며 사용할 수 없으면 UTC를 사용합니다. 보고서의 하루 경계를 일정하게 유지하려면 `Asia/Seoul`이나 `UTC` 같은 시간대를 지정하세요.

시간대를 바꾸면 자정 근처의 사용량이 인접한 날짜로 이동할 수 있습니다. 대시보드나 내보내기 결과를 비교할 때는 시간대와 기간을 모두 확인하세요.

## 변경 사항 검증

1. 복원할 수 있도록 이전 디렉터리 선택과 보고 기간을 기록하세요.
2. 앱이 변수를 상속하는지 확인하고 완전히 종료한 뒤 다시 여세요.
3. 로그를 다시 스캔하고 선택한 기간에 예상한 세션과 프로젝트가 표시되는지 확인하세요.
4. 기록이 사라지면 사용자 지정 값을 제거하고 다시 시작한 뒤 [문제 해결](/ko/docs/troubleshooting/)을 따르세요.
