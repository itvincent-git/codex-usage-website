## 대시보드를 사용하는 경우

“얼마나 사용했나?”, “사용량이 늘고 있나?”, “언제 급증했나?”를 확인할 때 여기서 시작하세요. 대시보드는 선택한 기간의 로컬 기록을 요약합니다. 일별, 월별, 프로젝트, 모델 및 세션 화면에서 합계의 원인을 살펴볼 수 있습니다.

## 숫자를 비교하기 전에 날짜 선택

1. 최근 7일 또는 30일 같은 기본 기간을 선택하세요.
2. 특정 주나 작업 기간은 사용자 지정 범위에서 시작일과 종료일을 모두 선택한 뒤 적용하세요.
3. 전체 토큰과 예상 비용을 확인하고 입력, 캐시 입력 및 출력 구성을 살펴보세요.
4. 화면이나 내보내기 결과를 비교할 때는 같은 기간을 사용하세요.

## 지표의 의미

- **토큰**은 모델이 처리한 텍스트의 단위입니다. 단어, 메시지 또는 작업 수가 아닙니다.
- **입력 토큰**은 모델에 전달된 컨텍스트이며 캐시에서 제공된 부분도 포함합니다.
- **캐시 입력 토큰**은 재사용된 입력입니다. 이미 입력에 포함되어 있으므로 다시 더하면 안 됩니다.
- **출력 토큰**은 생성된 콘텐츠를 나타냅니다.
- **캐시 적중률**은 전체 입력 중 캐시 입력의 비율입니다. 재사용 정도를 나타내며 계정의 잔여 한도가 아닙니다.
- **예상 비용**은 사용 가능한 모델 가격을 기준으로 계산한 미국 달러 참고값입니다. 구독 청구액이나 추가 요금 알림이 아닙니다.
- **일평균 사용량**은 선택한 기간의 합계를 비활성 날짜를 포함한 전체 일수로 나눈 값입니다. 일평균 토큰과 예상 비용을 보여줍니다.

> 가상 예시: 입력 토큰 100,000개에 캐시 토큰 60,000개가 포함되어 있고 출력이 20,000개라면 전체 사용량은 120,000개입니다. 비캐시 입력은 40,000개, 캐시 적중률은 60%입니다. 캐시 입력을 합계에 다시 더하지 마세요.

## 일별·월별 화면에서 급증 구간 찾기

**일별** 화면에서 사용량이 많은 날짜를 찾으세요. 날짜, 전체 토큰, 입력, 캐시 입력, 출력 또는 비용순으로 정렬하고 활동이 있는 날짜를 열어 세션을 살펴보세요. 연속된 비활성 날짜는 묶여 표시될 수 있습니다.

**월별** 화면에서 장기 추이를 확인한 뒤 일별 화면으로 돌아와 범위를 좁히세요. 구성 막대는 비캐시 입력, 캐시 입력 및 출력을 서로 겹치지 않는 세 부분으로 구분합니다.

예를 들어 이번 주 합계가 늘었다면 최고 사용일을 찾고 [프로젝트 및 모델](/ko/docs/projects-and-models/)을 비교한 뒤 관련 [세션](/ko/docs/sessions/)을 살펴보세요.

## 합계와 한도가 다를 수 있는 이유

대시보드 사용량은 로컬 로그에서, 실시간 한도는 계정 서비스에서 가져옵니다. 다른 기기의 사용, 로그 기록 및 새로고침 시점 때문에 값이 다를 수 있습니다. 토큰 합계를 잔여 한도로 직접 환산할 수는 없습니다.

최근 기록이 누락되었다면 기간을 확인하고 **로컬 로그 다시 스캔**을 실행하세요. 예상 비용이 0이면 가격 정보가 없을 수 있습니다. [모델 및 가격](/ko/docs/projects-and-models/)을 참고하세요.
