## 이 앱으로 할 수 있는 일

Codex Usage Desktop은 기존 로컬 Codex 세션 로그를 사용량 대시보드로 정리합니다. 사용한 토큰 수, 남은 계정 한도, 사용량이 가장 많은 프로젝트나 세션을 확인할 수 있습니다.

앱을 열기 전에 Codex CLI를 설치하고 사용해 읽을 세션 로그를 만들어 두세요. 별도 앱 계정, API 키, 분석 서버 또는 데이터베이스 설정은 필요하지 않습니다.

## 1단계: 컴퓨터에 맞는 버전 설치

[다운로드 페이지](/ko/download/)에서 컴퓨터에 맞는 파일을 선택하세요.

- **Windows 10/11 x64**: 설치 실행 파일을 열고 현재 사용자용 설치 절차를 따르세요.
- **Apple Silicon Mac**: Apple Silicon DMG를 선택하세요.
- **Intel Mac**: Intel DMG를 선택하세요. 이 Mac에 관하여에서 칩 종류를 확인할 수 있습니다.

macOS에서는 DMG를 열고 앱을 응용 프로그램 폴더로 옮긴 뒤 실행하세요. 시스템 실행 경고는 [문제 해결](/ko/docs/troubleshooting/)을 참고하세요.

## 2단계: 첫 사용 기록 확인

1. 평소 사용하는 터미널에서 Codex CLI를 열고 일반적인 상호작용을 완료해 세션 로그를 만드세요.
2. Codex Usage Desktop을 열고 첫 스캔이 끝날 때까지 기다리세요. 로컬 통계 색인을 생성하므로 로그가 많으면 시간이 더 걸릴 수 있습니다.
3. 최근 7일처럼 해당 세션이 포함된 대시보드 기간을 선택하세요.
4. 토큰이 표시되는지 확인한 다음 세션 화면에서 해당 작업을 찾으세요.

macOS의 기본 로그 위치는 `~/.codex`입니다. Windows의 탐색 방식은 [Windows 및 WSL](/ko/docs/windows-wsl/)을 참고하세요. 아무것도 표시되지 않으면 기간을 넓히고 **로컬 로그 다시 스캔**을 실행하세요.

## 3단계: 실시간 한도 확인

로컬 토큰 통계와 실시간 계정 한도는 데이터 출처가 다릅니다. 토큰은 표시되지만 한도가 없다면 로컬 Codex CLI의 로그인 상태를 확인하세요. 필요하면 다음 명령을 실행하세요.

```sh
codex login
```

로그인 후 앱으로 돌아와 한도를 확인하세요. 앱은 로컬 인증 정보를 재사용합니다. 별도의 한도 구간 시작 기능을 사용하기 전에는 [사용 한도](/ko/docs/quota/)를 읽어보세요.

## 처음 둘러볼 때의 추천 순서

1. [대시보드](/ko/docs/dashboard/)에서 입력, 캐시 입력, 출력 및 예상 비용의 의미를 알아보세요.
2. 작업을 계획하기 전에 [남은 한도와 초기화 카운트다운](/ko/docs/quota/)을 확인하세요.
3. [프로젝트 및 모델](/ko/docs/projects-and-models/)을 비교한 뒤 [세션 타임라인](/ko/docs/sessions/)에서 합계를 구성하는 작업을 살펴보세요.
4. 보고서나 추가 분석이 필요하면 [선택한 기간을 내보내세요](/ko/docs/export/).

통계에는 이 컴퓨터에서 읽을 수 있는 로그만 포함됩니다. 다른 컴퓨터의 작업은 자동으로 합쳐지지 않습니다. 데이터 처리 방식은 [개인정보 보호 및 네트워크 접근](/ko/docs/privacy/)을 참고하세요.
