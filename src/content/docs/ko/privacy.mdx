## 처음 사용할 때 필요한 것

Codex Usage Desktop 계정이나 OpenAI 또는 LiteLLM API 키는 필요하지 않습니다. 앱은 로컬 Codex 홈의 기존 로그를 읽고 실시간 한도 조회에 로컬 Codex 인증 정보를 재사용합니다.

## 컴퓨터에 보관되는 데이터

원본 로그는 로컬에서 읽습니다. 앱은 세션 로그를 업로드, 공유 또는 수정하지 않습니다. 집계된 통계는 운영체제의 앱 데이터 디렉터리에 있는 SQLite 캐시에 저장됩니다.

세션에는 민감한 프롬프트, 소스 코드, 명령 및 작업 디렉터리가 포함될 수 있습니다. 앱에 표시된다고 해서 업로드되었다는 뜻은 아닙니다.

## 앱이 네트워크에 연결하는 경우

- **실시간 한도**는 기존 로컬 Codex 인증 정보로 ChatGPT에 직접 조회합니다. 세션 로그는 첨부하지 않습니다.
- **모델 가격**은 공개 가격을 가져와 예상 비용과 카탈로그에 사용하도록 로컬에 캐시합니다.
- **기타 리소스**에는 공개 글꼴 파일, 한도 예측 및 업데이트 정보가 포함됩니다.

이 요청에는 세션 로그나 사용량 분석 데이터가 포함되지 않습니다. 로그를 로컬에서 처리하더라도 모든 기능이 오프라인으로 동작하는 것은 아닙니다. 한도와 업데이트에는 각 서비스가 필요하며 오프라인 가격 카탈로그에는 제한된 내장 데이터만 포함될 수 있습니다.

## 스크린샷, 내보내기 또는 이슈 보고 전

1. 스크린샷을 필요한 부분만 자르고 계정, 프로젝트 이름, 절대 경로 및 세션 제목을 가리세요.
2. 펼친 활동 내역의 프롬프트, 코드, 명령, 검색 및 파일 이름을 확인하세요.
3. 내보낸 모든 워크시트 또는 문서 전체를 검토하세요.
4. 보고서에는 필요한 진단 정보만 포함하세요. 전체 로그, 로그인 인증 정보 또는 키를 첨부하지 마세요.

앱은 로그를 업로드하지 않지만 직접 공유한 파일과 스크린샷의 공개 범위는 사용자가 결정합니다. 추가 확인은 [소스 코드](https://github.com/itvincent-git/codex-usage-desktop)나 [문제 해결](/ko/docs/troubleshooting/)을 참고하세요.
