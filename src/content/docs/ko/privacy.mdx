## 처음 사용할 때 필요한 것

앱은 로컬 Codex 로그를 읽고 기존 ChatGPT 로그인으로 실시간 한도를 조회할 수 있습니다. 로컬 사용량을 보는 데 별도의 Codex Usage Desktop 계정이나 API Key는 필요하지 않습니다.

[계정 관리](/ko/docs/accounts/)에서 ChatGPT 계정이나 API Key를 저장하면 인증 정보가 컴퓨터에 평문으로 저장되고, 파일 권한으로 접근이 제한됩니다. 공유용 백업과 문제 보고에는 인증 정보 파일을 제외합니다.

## 컴퓨터에 보관되는 데이터

원본 로그는 로컬에서 읽습니다. 앱은 세션 로그를 업로드, 공유 또는 수정하지 않습니다. 집계된 통계는 운영체제의 앱 데이터 디렉터리에 있는 SQLite 캐시에 저장됩니다.

세션에는 민감한 프롬프트, 소스 코드, 명령 및 작업 디렉터리가 포함될 수 있습니다. 앱에 표시된다고 해서 업로드되었다는 뜻은 아닙니다.

## 앱이 네트워크에 연결하는 경우

- **실시간 한도와 계정 상태**는 해당 로컬 인증 정보로 ChatGPT에 직접 조회합니다. 계정 페이지에서도 저장한 ChatGPT 계정의 상태를 백그라운드에서 새로 고칩니다. 이 요청에는 인증 정보가 사용되며 세션 로그는 제외됩니다.
- **모델 가격**은 공개 가격을 가져와 예상 비용과 카탈로그에 사용하도록 로컬에 캐시합니다.
- **세션 credits 조회**는 기본적으로 꺼져 있습니다. 켜면 ChatGPT 로그인 정보로 세션 ID를 ChatGPT에 직접 보내고, 반환된 차감액을 계정별로 로컬에 캐시합니다. 세션 내용은 기기에 남습니다.
- **기타 리소스**에는 공개 글꼴 파일과 codex-reset.com에서 제공하는 초기화 공지 및 예측이 포함됩니다.

실시간 한도 조회와 업데이트 확인에는 네트워크 연결이 필요합니다. 오프라인 가격 카탈로그에는 일부 내장 데이터만 표시될 수 있습니다.

## 스크린샷, 내보내기 또는 이슈 보고 전

1. 스크린샷을 필요한 부분만 자르고 계정, 프로젝트 이름, 절대 경로 및 세션 제목을 가리세요.
2. 펼친 활동 내역의 프롬프트, 코드, 명령, 검색 및 파일 이름을 확인하세요.
3. 내보낸 모든 워크시트 또는 문서 전체를 검토하세요.
4. 보고서에는 필요한 진단 정보만 포함하세요. 전체 로그, 로그인 인증 정보 또는 키를 첨부하지 마세요.

앱은 로그를 업로드하지 않지만 직접 공유한 파일과 스크린샷의 공개 범위는 사용자가 결정합니다. 추가 확인은 [소스 코드](https://github.com/itvincent-git/codex-usage-desktop)나 [문제 해결](/ko/docs/troubleshooting/)을 참고하세요.
