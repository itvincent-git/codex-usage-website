## 먼저 데이터 출처 확인

토큰 통계는 로컬 로그에 의존합니다. 실시간 한도에는 인증과 네트워크 연결이 필요합니다. 예상 비용에는 모델 가격도 필요합니다. 따라서 한도 카드가 없는 경우와 비용이 0인 경우는 확인할 사항이 다릅니다.

## 세션이 없거나 합계가 적은 경우

1. 평소 사용하는 Codex 환경에서 상호작용을 완료하고 JSONL 로그가 있는지 확인하세요.
2. 세션 검색을 지우고 기간을 넓혀 필터링 가능성을 배제하세요.
3. **로컬 로그 다시 스캔**을 실행하고 완료될 때까지 기다리세요.
4. `CODEX_HOME` 재정의 여부를 확인하세요. 변경 후 앱을 다시 시작하세요.
5. Windows에서는 [네이티브 및 WSL 탐색 순서](/ko/docs/windows-wsl/)를 확인하세요. 두 출처는 합쳐지지 않으며 다른 컴퓨터의 로그도 자동으로 포함되지 않습니다.

자정 근처의 기록이 인접한 날짜에 표시된다면 시스템 시간대와 [고급 설정](/ko/docs/advanced-settings/)의 `CODEX_USAGE_TIMEZONE`을 확인하세요. 표시 문제를 해결하려고 원본 로그를 수정하거나 삭제하지 마세요.

## 세션은 보이지만 실시간 한도가 없는 경우

1. 네트워크 연결을 확인하세요.
2. 앱이 사용하는 Codex CLI 환경에 로그인되어 있는지 확인하고 필요하면 해당 환경에서 `codex login`을 실행하세요.
3. 앱으로 돌아와 한도를 다시 확인하세요.
4. 사용자 지정 CLI 설치라면 `CODEX_CLI_PATH`를 확인하고 변경 후 다시 시작하세요.

한도 확인은 모델 한도를 소비하지 않습니다. 조회 실패를 진단하기 위해 한도 구간을 시작할 필요는 없습니다.

## 비용이 0이거나 값이 일치하지 않는 경우

모델 가격이 없으면 예상 비용은 기본적으로 0입니다. 모델 → 가격 카탈로그에서 검색하고 가격을 새로고침하세요. 예상 비용 0은 사용이 무료였다는 뜻이 아닙니다.

화면을 비교하기 전에 날짜, 시간대 및 필터를 맞추세요. 입력에는 캐시 입력이 포함되므로 중복 계산하지 마세요. 세션의 예상 한도 소비량과 현재 계정의 잔여 한도도 다릅니다. [대시보드 지표](/ko/docs/dashboard/)와 [세션 가이드](/ko/docs/sessions/)를 읽어보세요.

## 시스템 설치 경고

Windows 설치 프로그램은 아직 Authenticode 서명이 없어 SmartScreen 경고가 나타날 수 있습니다. 프로젝트 GitHub 릴리스에서 받은 파일인지 확인하세요. macOS Gatekeeper가 첫 실행을 차단하면 Gatekeeper를 비활성화하거나 우회하지 말고 시스템 설정 → 개인정보 보호 및 보안에서 앱을 허용하세요.

## 해결되지 않은 문제 보고

[프로젝트 이슈](https://github.com/itvincent-git/codex-usage-desktop/issues)에서 기존 보고를 확인하세요. 새 이슈에는 다음 내용을 포함하세요.

- 운영체제, 칩 아키텍처 및 앱 버전.
- 네이티브 또는 WSL 환경 여부와 사용자 지정 경로·시간대 여부.
- 재현 단계, 예상 동작과 실제 동작, 재스캔 후 결과 변화.
- 개인정보를 가린 오류 메시지 또는 최소한의 진단 정보.

계정, 키, 절대 경로, 비공개 프로젝트 이름 또는 전체 로그를 공개하지 마세요. 스크린샷 공유 전 [개인정보 보호 가이드](/ko/docs/privacy/)를 따르세요.
