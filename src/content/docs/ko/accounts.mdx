## 계정 페이지 열기

Codex Usage Desktop의 사이드바에서 **계정**을 선택합니다. ChatGPT 계정과 API Key 프로필을 여러 개 저장할 수 있습니다. 계정을 보거나 추가하거나 새로 고치는 동안 Codex는 현재 로그인을 계속 사용합니다. 브라우저 및 기기 코드 로그인에는 선택한 환경에 설치된 공식 Codex CLI가 필요합니다.

## ChatGPT 계정 추가하기

1. 로컬 Codex에 이미 로그인되어 있다면 **현재 Codex 계정 추가**로 해당 로그인을 저장하세요. Codex의 기본 OpenAI 제공업체를 사용하고 인증 정보가 파일에 저장된 API Key 로그인도 가져올 수 있습니다.
2. 다른 계정을 추가하려면 **계정 추가**(처음에는 **다른 계정 추가**)를 선택한 뒤 **브라우저에서 로그인**을 선택합니다. Codex에 아직 로그인하지 않았다면 빈 계정 페이지에서 바로 로그인할 수 있습니다.
3. 브라우저에서 사용할 ChatGPT 계정과 워크스페이스를 확인하고 인증을 마친 뒤 앱으로 돌아옵니다. 계정은 자동으로 저장됩니다.

**기기 코드 사용**을 선택할 수도 있습니다. 앱에서 안내하는 인증 페이지를 열고 코드를 입력합니다. 대화 상자를 닫은 뒤에는 **로그인 계속**을 선택해 돌아갈 수 있습니다. 로그인 시도를 종료하려면 **로그인 취소**를 선택합니다.

## API Key 추가하기

1. 저장된 계정이 없는 계정 페이지 또는 **계정 추가** 대화 상자에서 **API Key 추가**를 선택하세요.
2. 표시 이름과 키를 입력합니다. Base URL을 비워 두면 OpenAI의 기본 주소인 `https://api.openai.com/v1`을 사용합니다. 타사 서비스는 Responses API를 지원해야 합니다. `https://gateway.example.com/v1`처럼 전체 API 기본 주소를 입력합니다.
3. **API Key 저장**을 선택합니다. Codex에서 해당 프로필을 사용하려면 아래의 전환 단계를 따릅니다.

API Key 카드에는 프로필 이름과 Base URL이 표시됩니다. API 사용량과 청구 내역은 제공업체에서 확인합니다. 이전 토큰 사용량과 예상 비용은 선택한 Codex 디렉터리의 세션을 기준으로 집계되므로 여러 계정의 사용량을 포함할 수 있습니다.

## 한도 확인 및 새로 고침

ChatGPT 계정 카드에는 요금제에 따라 5시간 및 주간 한도 또는 월간 한도가 표시됩니다. 데이터가 있으면 초기화 시간, 구독 상태, 크레딧 잔액, 초기화 크레딧도 확인할 수 있습니다. 앱에서 백그라운드로 데이터를 갱신하며, 카드의 **새로 고침** 또는 **모두 새로 고침**을 사용할 수도 있습니다.

새로 고침이 실패하면 카드에 마지막으로 가져온 데이터임을 표시합니다. **데이터 상세**에서 갱신 시간과 오류를 확인할 수 있습니다. 로그인 안내가 표시되면 **다시 로그인**을 선택하고 같은 ChatGPT 계정과 워크스페이스를 사용합니다. 수치의 의미는 [사용 한도](/ko/docs/quota/)를 참고하세요.

## 계정 전환 및 Codex 재시작

1. 사용할 계정 카드에서 **Codex 로그인 전환**을 선택합니다. 선택한 Codex 환경에 로그인 설정이 기록됩니다. API Key로 전환하면 API 주소도 설정됩니다. ChatGPT로 돌아가면 API 제공업체 및 주소 설정이 제거됩니다.
2. **Codex에 설정됨**이 표시되면 Codex 데스크톱 클라이언트나 IDE를 재시작해 새 로그인을 불러옵니다.
3. Codex CLI를 사용한다면 현재 세션을 종료한 뒤 `codex --no-daemon`을 실행합니다. 또는 `codex app-server daemon stop`으로 백그라운드 서버를 종료한 뒤 Codex CLI를 평소처럼 실행합니다.

전환할 수 없다면 계정 페이지의 메시지를 확인합니다. 전환하려면 파일 기반 인증 정보가 필요합니다. Codex 설정에서 `cli_auth_credentials_store`를 생략하거나 `"file"`로 설정할 수 있습니다. 시스템 키체인이나 조직 정책으로 인해 설정을 쓸 수 없는 경우가 있습니다. 설정이 변경되었다는 메시지가 나오면 선택한 환경과 설정을 확인한 뒤 다시 시도합니다. WSL에서는 선택한 배포판에 Python 3.11 이상이 필요하며, 로그인에는 `setsid`도 필요합니다. 환경 선택 방법은 [Windows 및 WSL](/ko/docs/windows-wsl/)을 참고하세요.

## 계정 제거 및 인증 정보 보호

계정 카드의 **더 보기** 메뉴에서 **제거**를 선택하면 이 앱에 저장된 인증 정보와 상태 캐시가 삭제됩니다. 현재 계정을 제거하더라도 직접 전환하거나 로그아웃할 때까지 Codex는 기존 로그인을 계속 사용합니다.

저장된 ChatGPT 인증 정보와 API Key는 파일 권한으로 접근을 제한한 상태에서 컴퓨터에 평문으로 저장됩니다. 스크린샷을 공유할 때는 계정과 워크스페이스 정보를 가리고, 공유용 백업이나 문제 보고에 인증 파일이나 키가 포함되지 않도록 합니다. 자세한 내용은 [개인정보 보호 및 네트워크 액세스](/ko/docs/privacy/)를 참고하세요.
