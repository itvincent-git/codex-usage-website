## まず情報源を分けて考える

トークン統計にはローカルログ、現在の利用枠には認証と通信、推定コストにはモデル価格が必要です。「セッションはあるが利用枠がない」「トークンはあるがコストがゼロ」は別々に確認します。

## セッションがない・合計が少ない

1. 普段の環境で Codex を使い、JSONL ログができているか確認します。
2. 検索を消し、期間を広げて絞り込みを解除します。
3. ローカルログを再スキャンし、完了を待ちます。
4. `CODEX_HOME` の上書きを確認します。変更後はアプリを再起動します。
5. Windows は[ネイティブと WSL の検出順](/ja/docs/windows-wsl/)を確認します。両方や別の端末の記録は自動統合されません。

深夜の記録が前後の日にある場合は、[詳細設定](/ja/docs/advanced-settings/)でシステム時区と `CODEX_USAGE_TIMEZONE` を確認します。表示を直すために元ログを編集・削除しないでください。

## セッションはあるが利用枠が出ない

1. ネットワーク接続を確認します。
2. アプリが使う Codex CLI 環境でログイン済みか確認し、必要なら `codex login` を実行します。
3. アプリに戻って利用枠を再取得します。
4. CLI が独自の場所なら `CODEX_CLI_PATH` を確認し、変更後に再起動します。

利用枠の確認はモデルの利用枠を消費しません。取得失敗の調査にウィンドウの開始は不要です。

## コストがゼロ・ページの値が違う

価格のないモデルは推定コストがゼロになります。モデルの価格カタログで検索・更新してください。ゼロの推定は無料の証明ではありません。

比較前に期間、タイムゾーン、検索条件を揃えます。入力にはキャッシュを含むため重複して足しません。セッションの推定消費割合と現在の残量も別です。[指標の説明](/ja/docs/dashboard/)と[セッションガイド](/ja/docs/sessions/)を確認してください。

## インストール時の警告

Windows は Authenticode 未署名のため SmartScreen が警告する場合があります。プロジェクトの GitHub Release から入手したファイルか確認します。macOS の Gatekeeper が初回起動を止めた場合は「システム設定 → プライバシーとセキュリティ」で許可し、Gatekeeper 自体は無効化・回避しません。

## 解決しない場合の報告

[プロジェクトの Issues](https://github.com/itvincent-git/codex-usage-desktop/issues)で既存の報告を探します。新規報告では次を添えます。

- OS、チップの種類、アプリのバージョン。
- ネイティブか WSL か、独自のパスや時区の有無。
- 再現手順、期待した結果、実際の結果、再スキャン後の変化。
- 機密情報を隠したエラーや必要最小限の診断。

アカウント、キー、絶対パス、私的なプロジェクト名、完全なログは公開しないでください。画像を共有する前に[プライバシーガイド](/ja/docs/privacy/)を確認します。
