## 現在の利用枠

端末内の Codex ログイン情報を使い、ChatGPT から 5 時間枠と週次・月次枠を直接取得します。残量とリセット時刻を確認でき、データがある場合はリセットクレジットや予測も表示します。

## 常に見える場所へ

macOS のメニューバーや Windows のシステムトレイに利用枠を表示できます。表示テキストとカウントダウンの単位は設定で変更できます。

取得できない場合は `codex auth login` で Codex CLI のログインを確認し、アプリを更新してください。ローカルログのトークン集計とアカウントの現在の利用枠は別の情報源を使い、更新時刻が異なる場合があります。
