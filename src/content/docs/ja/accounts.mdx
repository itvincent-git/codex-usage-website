## アカウント画面を開く

Codex Usage Desktop のサイドバーで **アカウント** を選びます。複数の ChatGPT アカウントと API Key プロファイルを保存できます。アカウントの表示、追加、更新中も、Codex は現在のログインを使い続けます。ブラウザやデバイスコードでログインするには、選択中の環境に公式の Codex CLI が必要です。

## ChatGPT アカウントを追加する

1. 端末の Codex がすでにログイン済みの場合は、**現在の Codex アカウントを追加**でそのログインを保存します。Codex の組み込み OpenAI プロバイダーを使用し、認証情報をファイルに保存している API キーログインも取り込めます。
2. 別のアカウントを追加するには、**アカウント追加**（初回は **別のアカウントを追加** と表示される場合があります）から **ブラウザでログイン** を選びます。Codex にログインしていない場合は、一覧が空の状態から直接ブラウザでログインできます。
3. ブラウザで使う ChatGPT アカウントとワークスペースを確認し、認証を完了してアプリに戻ります。アカウントは自動で保存されます。

**デバイスコードを使用** を選ぶ場合は、アプリの案内から認証ページを開き、コードを入力します。ダイアログを閉じたあとも **ログインを続行** から戻れます。中止する場合は **ログインをキャンセル** を選びます。

## API Key を追加する

1. 保存済みアカウントがないアカウント画面、または **アカウントを追加** ダイアログで **API Key を追加** を選びます。
2. 表示名とキーを入力します。Base URL を空欄にすると、OpenAI の既定のエンドポイント `https://api.openai.com/v1` が使われます。サードパーティーのサービスには Responses API のサポートが必要です。`https://gateway.example.com/v1` のように、API のルート URL を入力します。
3. **API Key を保存** を選びます。Codex で使うときは、後述の手順で切り替えます。

API Key のカードには表示名と Base URL が表示されます。API の使用量と請求はプロバイダーで確認できます。過去のトークン使用量や推定コストは、選択中の Codex ディレクトリにあるセッションから集計されるため、複数のアカウントの使用量を含むことがあります。

## 利用枠を確認・更新する

ChatGPT アカウントのカードには、プランに応じて 5 時間と週間の利用枠、または月間利用枠が表示されます。データが取得できる場合は、リセット時刻、契約状況、クレジット残高、リセットクレジットも表示されます。バックグラウンドで自動更新されるほか、各カードの **更新** や **すべて更新** でも更新できます。

更新に失敗すると、カードに前回取得できたデータだと表示されます。**データ詳細** を開くと、更新時刻とエラーを確認できます。ログインを求められた場合は **再ログイン** を選び、同じ ChatGPT アカウントとワークスペースを使います。数値の見方は[利用枠と制限](/ja/docs/quota/)を参照してください。

## ログインを切り替えて Codex を再起動する

1. 使いたいカードで **Codex のログインを切り替え** を選びます。選択中の Codex 環境にログイン設定が書き込まれます。API Key に切り替えると API のエンドポイントも設定されます。ChatGPT に戻すと API のプロバイダーとエンドポイントの設定が削除されます。
2. **Codex に設定済み** と表示されたら、Codex デスクトップクライアントや IDE を再起動して、新しいログインを読み込みます。
3. Codex CLI の場合は、現在のセッションを終了し、`codex --no-daemon` を実行します。または `codex app-server daemon stop` でバックグラウンドサーバーを停止し、Codex CLI を通常どおり起動します。

切り替えができない場合は、アカウント画面のメッセージを確認してください。切り替えにはファイルに保存された認証情報が必要です。Codex の設定で `cli_auth_credentials_store` を省略するか、`"file"` に設定できます。システムのキーチェーンや管理ポリシーによって書き込みが制限されることがあります。設定の変更が表示された場合は、環境と設定を確認してから再試行してください。WSL では選択中のディストリビューションに Python 3.11 以降が必要で、ログインには `setsid` も必要です。環境の選び方は [Windows と WSL](/ja/docs/windows-wsl/) を参照してください。

## アカウントを削除し、認証情報を保護する

カードのメニューから **削除** を選ぶと、このアプリに保存した認証情報と状態のキャッシュが削除されます。現在のアカウントを削除した場合も、切り替えやログアウトを行うまで Codex はそのログインを使い続けます。

保存した ChatGPT の認証情報と API Key は、ファイル権限でアクセスを制限したうえで、ローカルに平文で保存されます。スクリーンショットを共有するときはアカウントやワークスペースの情報を隠し、共有用のバックアップやバグ報告には認証情報ファイルやキーを含めないでください。詳しくは[プライバシーとネットワークアクセス](/ja/docs/privacy/)を参照してください。
