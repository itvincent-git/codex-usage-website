## ローカルのセッションデータ

Codex ホーム内のファイルを端末内で読み取ります。セッションログをアップロード、共有、変更することはありません。集計した使用量は OS のアプリデータディレクトリにある SQLite キャッシュに保存します。OpenAI または LiteLLM の API キーをアプリに入力・保存する必要はありません。

## ネットワーク通信

現在の利用枠は、ローカルの Codex 認証情報を使って ChatGPT に直接問い合わせます。この要求にセッションログは含まれません。公開フォント、モデル価格、利用枠の予測、更新情報も取得します。価格はローカルにキャッシュされ、これらの要求にもログや使用状況の分析データは含まれません。

セッションには機密性のあるプロンプト、コード、コマンドが含まれる場合があります。ローカルデータや自身で出力したファイルは適切に扱ってください。[ソースコード](https://github.com/itvincent-git/codex-usage-desktop)を確認できます。
