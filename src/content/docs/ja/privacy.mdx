## 最初に必要な情報

Codex Usage Desktop のアカウント登録や OpenAI・LiteLLM API キーの入力・保存は不要です。ローカルの Codex ホームにある既存ログを読み、現在の利用枠には既存のローカル認証を使います。

## 端末に残るもの

元ログは端末内で読み取ります。アプリはセッションログをアップロード、共有、変更しません。集計は OS のアプリデータディレクトリにある SQLite キャッシュに保存します。

セッションには機密のプロンプト、コード、コマンド、作業ディレクトリが含まれる場合があります。画面で見られることは、アップロードされたことを意味しません。

## 通信する場面

- **現在の利用枠**：既存のローカル Codex 認証で ChatGPT に直接問い合わせます。ログは添付しません。
- **モデル価格**：公開価格を取得し、コスト推定とカタログ用に端末内でキャッシュします。
- **その他**：公開フォント、利用枠予測、更新情報を取得します。

これらの要求にセッションログや使用状況の分析データは含みません。ログのローカル処理と、全機能のオフライン動作は別です。利用枠と更新には接続が必要で、オフライン価格には限られた内蔵データのみの場合があります。

## 画像・出力・報告を共有する前に

1. 必要な範囲だけ切り取り、アカウント、プロジェクト名、絶対パス、タイトルを隠します。
2. 展開した活動のプロンプト、コード、コマンド、検索、ファイル名も確認します。
3. 出力ファイルの全シートまたは全文を確認します。
4. 問題報告には必要な診断のみを含め、完全なログ、認証情報、キーは添付しません。

アプリはログをアップロードしませんが、自分で共有するファイルや画像の公開範囲は自分で選びます。[ソースコード](https://github.com/itvincent-git/codex-usage-desktop)と[トラブルシューティング](/ja/docs/troubleshooting/)も参照できます。
