## エクスポートを使う場面

週次報告、期間の比較、表計算での追加分析に、選択期間の集計を保存できます。コマンドやプロンプトを調べる場合は[セッション時系列](/ja/docs/sessions/)を使います。

## 期間を選んで保存する

1. ダッシュボードで期間を選びます。週次報告なら開始日と終了日を指定します。
2. スキャン完了を待ち、合計と推定コストが対象期間に合っているか確認します。
3. エクスポートから Excel `.xlsx` または Markdown `.md` を選びます。
4. 保存先を選び、保存後に開いて日付、タイムゾーン、合計を確認します。

## 形式の選び方

- **Excel**：絞り込み、計算、グラフに向いています。Summary、Daily、Models、Projects の 4 シートに概要・日次・モデル・プロジェクトの統計を保存します。
- **Markdown**：メモや報告で集計を読む、引用する場合に便利です。共有前にテキストエディターで確認・編集できます。

別の週を保存する場合は期間を変えて再出力してください。ファイル名を変えるだけでは中身は変わりません。

## コストを比較する際の注意

コストは利用可能なモデル価格による推定値で、請求額ではありません。不明なモデルはゼロとして扱います。比較前に期間、タイムゾーン、価格条件を確認し、集計条件の違いを使用量の変化と取り違えないようにします。

## 共有前に確認する

ファイルにはプロジェクト名、ディレクトリパス、利用傾向が含まれる場合があります。すべてのシートまたは Markdown 全体を確認し、私的な名前、パス、アカウント情報を隠してから共有してください。会話全文がないからといって、そのまま公開できるとは限りません。

プロジェクトの値が不自然な場合は[プロジェクトとモデル](/ja/docs/projects-and-models/)から該当セッションを調べます。
