## このアプリでできること

Codex Usage Desktop は、端末にある Codex セッションログを使用量ダッシュボードにまとめます。「どれだけトークンを使ったか」「利用枠がどれだけ残っているか」「どのプロジェクトやセッションで使ったか」を確認できます。

先に Codex CLI をインストールして使い、読み取れるセッションログを作成してください。このアプリ専用のアカウント、API キー、分析サーバー、データベースの設定は不要です。

## 手順 1：端末に合うアプリをインストール

[ダウンロードページ](/ja/download/)で、お使いの端末に合うファイルを選びます。

- **Windows 10/11 x64**：インストーラーを実行し、現在のユーザー向けにインストールします。
- **Apple Silicon Mac**：Apple Silicon 用 DMG を選びます。
- **Intel Mac**：Intel 用 DMG を選びます。チップの種類は「この Mac について」で確認できます。

macOS では DMG を開き、アプリを Applications に移動してから起動します。OS の警告が出た場合は[トラブルシューティング](/ja/docs/troubleshooting/)を確認してください。

## 手順 2：最初の使用量を確認

1. 普段のターミナルで Codex CLI を使い、通常のやり取りを 1 回行います。
2. Codex Usage Desktop を開き、最初のスキャンが完了するまで待ちます。端末内に統計用のインデックスを作成するため、ログが多い場合は時間がかかります。
3. ダッシュボードで、その作業を含む期間を選びます。最初は過去 7 日間などが便利です。
4. トークンが表示されたら「セッション」を開き、先ほどの記録を探します。

macOS の通常の読み取り先は `~/.codex` です。Windows は [Windows と WSL](/ja/docs/windows-wsl/) の検出ルールを参照してください。見つからない場合は期間を広げ、「ローカルログを再スキャン」を実行します。

## 手順 3：現在の利用枠を取得

ローカルのトークン集計と現在の利用枠は別の情報源です。トークンは表示されても利用枠が出ない場合、Codex CLI へのログインを確認します。必要ならターミナルで実行してください。

```sh
codex login
```

ログイン後、アプリに戻って利用枠を確認します。既存のローカル認証情報が使われます。ウィンドウを開始する操作との違いは[利用枠と上限](/ja/docs/quota/)を参照してください。

## 最初はこの順番で使う

1. [ダッシュボード](/ja/docs/dashboard/)で入力・キャッシュ・出力と推定コストを読みます。
2. [利用枠](/ja/docs/quota/)で残量とリセットまでの時間を確認します。
3. [プロジェクトとモデル](/ja/docs/projects-and-models/)を比較し、[セッション詳細](/ja/docs/sessions/)で作業内容を調べます。
4. 報告や追加の計算には[エクスポート](/ja/docs/export/)を使います。

集計の対象は、この端末で読み取れるログです。別の端末での作業は自動統合されません。保存と通信については[プライバシー](/ja/docs/privacy/)を参照してください。
