## インストール

[ダウンロードページ](/ja/download/)から Windows x64 インストーラー、Apple Silicon 用 DMG、Intel Mac 用 DMG を選びます。Windows は現在のユーザー向けにインストールされます。macOS では DMG を開き、アプリを Applications に移動してください。

## 最初のスキャン

1. 先に Codex CLI を使い、端末内にセッションログを作成します。
2. Codex Usage Desktop を開くと、ログを検出し、ローカルの SQLite インデックスを作成します。
3. 期間を選び、ダッシュボード、モデル、プロジェクト、日次、月次、セッションを確認します。

別のアカウント、API キー、分析サーバー、データベース設定は不要です。利用枠の取得にはローカルの Codex CLI へのログインが必要です。必要なら `codex auth login` を実行し、アプリを更新してください。

リリースノート、開発・貢献については [GitHub プロジェクト](https://github.com/itvincent-git/codex-usage-desktop) を参照してください。
