## 什么时候看这个页面

想知道“今天用了多少”“最近用量是否增加”或“哪个时间段突然升高”，先看看板。它汇总所选日期范围内的本地记录，再让你通过每日、每月、项目、模型和会话视图继续追查。

## 先选时间，再读数值

1. 在日期选择器中选择最近 7 天、30 天等预设范围。
2. 要查看某一周或某段工作，选择自定义日期，选好开始和结束日期后应用。
3. 先读总 Token 与预估成本，再看输入、缓存和输出的构成。
4. 对比项目、模型或导出数据时，使用相同日期范围。

## 各项指标是什么意思

- **Token**：模型处理文本的计量单位，不能直接当成字数、消息条数或任务数量。
- **输入 Token**：发送给模型处理的上下文，包含其中命中缓存的部分。
- **缓存输入 Token**：输入中被复用的部分，已经计入输入，不能再加一次。
- **输出 Token**：模型生成内容所使用的 Token。
- **缓存命中率**：缓存输入占输入总量的比例。它描述输入的复用程度，不表示账户还剩多少额度。
- **预估成本**：按可用模型价格计算的美元参考值，不是订阅账单，也不是额外收费通知。
- **日均用量**：将所选范围总量除以范围内的天数，包含无活动日期，展示每日平均 Token 和预估成本。

> 虚构示例：输入 100,000 Token，其中缓存 60,000，输出 20,000。总量为 120,000；未缓存输入为 40,000，缓存命中率为 60%。不能把缓存再加到总量中。

## 用每日和每月视图找出峰值

**每日**适合查“哪天用得最多”。你可以按日期、总 Token、输入、缓存、输出或成本排序，点击有活动的日期查看当天会话。连续无活动日期可能折叠显示。

**每月**适合观察长期变化，再回到每日视图缩小排查范围。比较柱状构成时，未缓存输入、缓存输入和输出是互不重复的三部分。

例如本周总量明显增加，可以先在每日视图找到高峰，再去[项目与模型](/zh/docs/projects-and-models/)确认主要来源，最后在[会话](/zh/docs/sessions/)中查看当天做了什么。

## 为什么看板和额度数字不一致

看板计算的是本地日志中的用量，实时额度读取的是账户当前状态。其他设备上的使用、日志写入和刷新时间都可能使两者不同，不能用 Token 总量直接换算剩余额度。

最新记录缺失时，确认日期范围后使用“重新扫描本地日志”。成本为零也可能是模型没有可用定价，详见[模型与价格](/zh/docs/projects-and-models/)。
