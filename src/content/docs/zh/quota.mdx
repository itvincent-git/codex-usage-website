## 实时额度

应用使用本机已有的 Codex 登录状态，直接向 ChatGPT 请求当前的 5 小时以及每周或每月限制，并展示剩余额度和重置时间。底层数据可用时，也会显示重置额度与额度预测。

## 随时查看

可在 macOS 菜单栏或 Windows 系统托盘显示额度。显示文字和倒计时单位可在应用设置中调整。

若实时额度不可用，先用 `codex auth login` 确认 Codex CLI 已登录，再刷新应用。本地日志的 Token 统计与实时账户额度来自不同数据源，更新时间可能不同。
