## 先分清：已用多少与还能用多少

看板上的 Token 总量回答“本机记录了多少用量”；额度卡片回答“账户现在还能用多少”。额度来自 ChatGPT 的实时账户状态，使用本机已有的 Codex 登录信息查询。

## 第一次查询额度

1. 确认平时使用的 Codex CLI 已登录；必要时运行 `codex login`。
2. 打开看板的额度卡片，使用“查询额度”。实时查询需要网络连接。
3. 分别查看 5 小时限制与每周或每月限制的剩余额度、重置时间和倒计时。具体显示取决于账户返回的数据。

两个窗口应分别阅读。即使 5 小时额度充足，较长周期的额度也可能接近上限。倒计时对应各自窗口，不代表所有额度会一起重置。

## 如何读懂百分比和倒计时

- **剩余额度**：当前窗口还可以使用的比例。它是额度比例，不是固定的可用 Token 数。
- **重置时间与倒计时**：该窗口的重置时刻，以及距离该时刻还有多久。
- **重置额度与预测**：只有底层数据可用时才会显示。预测可能变化，不能当成保证。

> 虚构示例：5 小时剩余 70%、每周剩余 20%，表示短周期余量较多，但长周期已经使用较多。不能把两者相加，也不能用 70% 乘本地 Token 总量来推算还能用多少。

## “查询额度”和“启动额度窗口”有何区别

**查询额度**只读取服务器上的当前状态，不会启动或延长 5 小时窗口，也不会消耗模型额度。日常只想看余量时，使用这个操作即可。

**启动额度窗口**会发送一次最小 Codex 请求，消耗少量 5 小时及每周额度，并在发送前请你确认。它只对符合条件的订阅开放，且要等现有 5 小时窗口结束后才能使用；窗口仍在生效时不可用。只有你希望主动开始一个新窗口时才需要它。

## 工作时随时查看

在“设置”中找到菜单栏或系统托盘选项，选择要显示的额度文字和倒计时单位。macOS 用户可从菜单栏查看，Windows 用户可从系统托盘查看，无需一直打开主窗口。

想了解公告、历史变化或重置额度的到期时间，继续阅读[额度重置](/zh/docs/resets/)。

## 查询失败或与会话不一致

先检查网络和 CLI 登录状态，再查询一次。会话列表中的百分比表示**该会话预估消耗的额度**；这里显示的是**账户当前剩余的额度**。两者含义不同，更新时间也可能不同。更多排查方法见[故障排查](/zh/docs/troubleshooting/)。
