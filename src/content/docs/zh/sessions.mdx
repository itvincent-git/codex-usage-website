## 查找会话

按日期浏览会话，查看当天的 Token 总量。按标题、项目或模型搜索；每段会话可查看 Token 总量、输入、缓存、输出与预估成本。若本地日志包含足够的额度记录，列表还会显示该会话预估消耗的 5 小时与每周额度。额度百分比为估算值，不等同于实时剩余额度。

## 检查活动

打开会话可按时间线查看记录。视日志内容而定，可能包括命令与工具、网页搜索、补丁与差异、长时间运行的命令、子代理层级和剩余额度变化。需要核对原始记录时可打开 JSONL 链接。

在单条会话明细中，先看整段会话的 Token 总量、输入、缓存和输出，再沿时间线查看各用量节点的累计 Token、相对上次记录新增的 Token 及其构成。缓存 Token 包含在输入 Token 内，不应与输入重复相加。

会话列表中的 5 小时与每周额度百分比表示这段会话的**预估消耗量**。只有本地日志包含足够的额度记录时才能估算；它们不是实时剩余额度，也不能直接由 Token 数量换算得出。

详情仅能展示本地 Codex 日志已记录的信息。日志可能包含敏感提示词、代码和命令，分享截图或导出文件时请留意。
