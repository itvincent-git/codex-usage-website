## 适合哪些用户

如果你在 Windows 10/11 x64 上使用 Codex，或者平时在 WSL 终端里运行 Codex，请先了解应用会选择哪份日志。通常安装后即可自动发现，无需一开始就配置路径。

## 自动发现顺序

1. 应用优先使用通过**选择 Codex 目录**保存的目录。其次使用已设置的非空 `CODEX_HOME`。
2. 没有手动指定目录时，应用先在 `%USERPROFILE%\.codex` 的 `sessions` 和 `archived_sessions` 中查找 `.jsonl` 和 `.jsonl.zst` 文件。
3. 没有找到原生会话文件时，应用尝试使用默认 WSL 发行版的 `$HOME/.codex`。若 WSL 不可用，则回到原生目录。

Windows 原生与 WSL 会话不会合并，多个 WSL 发行版也不会合并，以避免重复统计。

## 在 WSL 中工作却看不到会话

先确认你平时使用的发行版是不是默认发行版。在 Windows PowerShell 中运行以下只读命令，可以列出发行版，带星号的项目为默认项：

```powershell
wsl --list --verbose
```

确认该发行版中已有 Codex 会话。自动发现时，Windows 原生目录只要存在支持的会话文件，就会优先使用原生目录。

如果恢复面板提供**选择 Codex 目录**，可选择包含 `sessions` 或 `archived_sessions` 的 WSL Codex 主目录。应用会保存选择并立即重新扫描。也可以把 `CODEX_HOME` 设为 Windows 可访问的 WSL 路径，例如 `\\wsl.localhost\Ubuntu\home\example\.codex`。生效方式见[进阶设置](/zh/docs/advanced-settings/)。

## 安装与实时额度

Windows 安装包按当前用户安装。由于尚未进行 Authenticode 签名，SmartScreen 可能显示“无法识别的应用”，继续前请确认文件来自[官方下载入口](/zh/download/)指向的项目 GitHub Release。

如果能看到会话但无法查询额度，请确认应用所使用环境中的 Codex CLI 已登录，再查询。日志读取成功与账户额度查询成功是两件独立的事，更多步骤见[故障排查](/zh/docs/troubleshooting/)。
