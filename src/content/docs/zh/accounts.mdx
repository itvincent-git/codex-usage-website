## 打开账号页面

在 Codex Usage Desktop 的侧边栏选择 **账号**。你可以同时保存多个 ChatGPT 账号和 API Key 配置。查看、添加和刷新账号时，Codex 会继续使用当前登录。浏览器登录和设备码登录需要所选环境中安装了官方 Codex CLI。

## 添加 ChatGPT 账号

1. 如果 Codex 已在本机登录，选择 **添加当前 Codex 账号**，把现有登录保存到列表。
2. 要添加其他账号，选择 **添加账号**（首次使用时可能显示 **添加其他账号**），再选 **在浏览器中登录**。还未登录 Codex 时，也可以直接从空白账号页开始登录。
3. 在浏览器中确认目标 ChatGPT 账号和工作区，完成授权后返回应用。账号会自动保存。

也可以选择 **使用设备码登录**，打开应用提供的授权页面并输入设备码。关闭登录窗口后可通过 **继续登录** 返回。要结束本次授权，请选择 **取消登录**。

## 添加 API Key

1. 在账号页或 **添加账号** 对话框中选择 **添加 API Key**。
2. 填写便于识别的名称和密钥。使用 OpenAI 官方接口时，Base URL 留空即可，默认使用 `https://api.openai.com/v1`。第三方服务须支持 Responses API，请填写完整的 API 根地址，例如 `https://gateway.example.com/v1`。
3. 选择 **保存 API Key**。这一步只保存配置。要实际使用它，继续执行下面的切换步骤。

API Key 卡片显示名称和 Base URL。API 用量与账单请到服务商处查看。历史 Token 和预估成本仍按所选 Codex 目录中的会话统计，可能包含多个账号的用量。

## 查看并刷新额度

ChatGPT 账号卡片按套餐显示 5 小时和每周额度，或每月额度，并在数据可用时显示重置时间、订阅状态、余额与重置额度。应用会在后台刷新，也可以点卡片上的 **刷新**，或用 **全部刷新** 更新所有 ChatGPT 账号。

刷新失败时，卡片会标记上次成功获取的数据。展开 **数据详情** 查看更新时间和错误。如果提示需要登录，选择 **重新登录**，使用同一 ChatGPT 账号和工作区。关于各项数值的含义，见[额度与限制](/zh/docs/quota/)。

## 切换账号并重启 Codex

1. 在目标账号卡片上选择 **切换到此账号**。切换会写入所选 Codex 环境的登录配置。切换到 API Key 时也会设置 API 端点，切回 ChatGPT 时会清除该 API 提供商和端点设置。
2. 看到 **Codex 已配置** 后，重启正在使用的 Codex 桌面客户端或 IDE，让它加载新登录。
3. 如果用的是 Codex CLI，退出当前会话，再运行 `codex --no-daemon`。也可运行 `codex app-server daemon stop` 停止后台服务，然后正常启动 Codex CLI。

如果切换按钮不可用，先检查页面提示。切换支持使用文件凭据的环境，在 Codex 配置中可省略 `cli_auth_credentials_store` 或设为 `"file"`。系统密钥链和组织管理策略可能阻止写入。如果提示配置已更改，先核对当前环境和配置，再重试。WSL 需要在所选发行版中安装 Python 3.11 或更新版本，授权登录还需要 `setsid`。有关环境选择，见 [Windows 与 WSL](/zh/docs/windows-wsl/)。

## 移除账号和保护凭据

账号卡片的 **更多** 菜单中可选择 **移除**。这会删除本应用保存的凭据和状态缓存。若移除的是当前账号，Codex 会继续使用该登录，直到你主动切换或退出。

应用以明文在本机保存已添加账号的凭据和 API Key，并通过文件权限限制访问。分享截图、备份或提交问题时，请遮盖账号和工作区信息，并排除凭据文件和密钥。详见[隐私与网络访问](/zh/docs/privacy/)。
