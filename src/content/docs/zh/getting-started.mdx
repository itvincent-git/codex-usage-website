## 这个应用能帮你做什么

Codex Usage Desktop 把本机已有的 Codex 会话日志整理成用量看板。你可以用它回答三个问题：最近用了多少 Token、账户还剩多少额度、哪些项目和会话消耗最多。

它是查看和分析用量的桌面应用。开始前，请先安装并使用 Codex CLI，让电脑上有可读取的会话日志。无需为本应用另建账号、填写 API Key、部署服务器或配置数据库。

## 第一步：安装适合你电脑的版本

前往[下载页](/zh/download/)，按设备选择安装包：

- **Windows 10/11 x64**：下载并运行安装程序，按提示完成当前用户安装。
- **Apple 芯片 Mac**：选择 Apple Silicon DMG。
- **Intel Mac**：选择 Intel Mac DMG。在 Mac 的“关于本机”中可以确认芯片类型。

macOS 用户打开 DMG 后，将应用拖入“应用程序”，再从那里启动。遇到系统拦截时，按[故障排查](/zh/docs/troubleshooting/)中的安装提示处理。

## 第二步：读取你的第一次用量

1. 在平时使用的终端里打开 Codex CLI，完成一次正常的交互，确保已有会话日志。
2. 打开 Codex Usage Desktop，等待首次扫描完成。应用会在本机建立统计索引，日志较多时请等扫描结束再看总量。
3. 在看板选择覆盖刚才会话的日期范围，例如最近 7 天。
4. 确认看板出现 Token 数值，再打开“会话”，找到刚才的记录。

macOS 通常从 `~/.codex` 读取；Windows 的原生目录与 WSL 发现规则见 [Windows 与 WSL](/zh/docs/windows-wsl/)。如果没有记录，先扩大日期范围，再使用“重新扫描本地日志”。

## 第三步：连接实时额度

Token 统计来自本地日志，实时额度来自账户服务，两者可以分别成功或失败。如果 Token 已出现，但额度卡片不可用，请确认本机 Codex CLI 已登录。必要时在终端运行：

```sh
codex login
```

完成登录后，返回应用查询额度。应用复用本机已有的登录状态，无需再粘贴密钥。关于查询与启动窗口的区别，请阅读[额度与限制](/zh/docs/quota/)。

## 第一次使用，建议这样浏览

1. **看总量**：在[看板](/zh/docs/dashboard/)认识输入、缓存、输出和预估成本。
2. **看还能用多少**：在[额度指南](/zh/docs/quota/)了解剩余百分比与重置倒计时。
3. **找出来源**：在[项目与模型](/zh/docs/projects-and-models/)比较用量，再打开[会话详情](/zh/docs/sessions/)查看具体活动。
4. **保存结果**：需要周报或进一步计算时，[导出 Excel 或 Markdown](/zh/docs/export/)。

这些统计只覆盖本机能够读取的日志。其他电脑上的工作不会自动合并。日志的存储与联网范围见[隐私说明](/zh/docs/privacy/)。
