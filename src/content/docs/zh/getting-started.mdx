## 安装

从[下载页](/zh/download/)获取 Windows x64 安装包、Apple 芯片 DMG 或 Intel Mac DMG。Windows 安装包按当前用户安装；在 macOS 上打开 DMG，把应用移到“应用程序”。

## 首次扫描

1. 先使用 Codex CLI，确保本机 Codex 目录中已有会话日志。
2. 打开 Codex Usage Desktop；应用会发现日志并创建本地 SQLite 索引。
3. 选择日期范围，进入看板、模型、项目、每日、每月或会话视图。

无需另建账号、填写 API Key、部署分析服务或配置数据库。实时额度需要本机 Codex CLI 已登录；必要时运行 `codex auth login`，然后刷新应用。

发行说明、开发与贡献说明见 [GitHub 项目](https://github.com/itvincent-git/codex-usage-desktop)。
