## 什么时候使用导出

需要做周报、比较不同时间段或在表格中继续计算时，可以把所选范围的统计保存为文件。导出面向用量汇总；查看某条命令或提示词应使用[会话时间线](/zh/docs/sessions/)。

## 从选定范围到保存文件

1. 在看板选择需要的日期范围。周报可以使用自定义日期，明确选好起止日期。
2. 确认扫描完成，并核对总 Token 与预估成本是否符合要记录的范围。
3. 使用“数据导出”，选择 Excel `.xlsx` 或 Markdown `.md`。
4. 在保存对话框中选择文件位置并保存，再打开文件核对日期范围、时区和总量。

## 应该选择哪种格式

- **Excel**：适合筛选、计算和制作图表。工作簿包含 Summary、Daily、Models、Projects 四个工作表，分别提供摘要、每日、模型和项目统计。
- **Markdown**：适合在笔记或报告中阅读、引用汇总数据。分享前可以先用文本编辑器检查和删去敏感内容。

导出使用选定范围的数据。若你需要另一周的结果，请切换日期后重新导出，不要只修改文件名。

## 如何理解导出的成本

成本以可用模型价格估算，不是订阅账单。未知模型的估算默认为零。比较两个导出文件时，先确认日期范围、时区和价格条件，避免把统计口径变化当成用量变化。

## 分享之前检查什么

导出文件仍可能包含项目名称、目录路径和使用习惯。请检查每个工作表或整份 Markdown，遮盖私人项目、路径、账户信息等细节后再分享。不要因为文件没有完整会话内容，就认为可以直接公开。

如果发现某个项目的数值异常，回到[项目与模型](/zh/docs/projects-and-models/)定位，再查看相关会话。
