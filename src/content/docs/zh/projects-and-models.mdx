## 项目视图

打开项目视图，按项目目录对比 Token 用量与预估成本。每一行同时展示每日 Token 柱状图、成本趋势线，以及非缓存输入、缓存输入和输出的构成。

选择日期范围，再按 Token 总量或成本排序，快速找出用量较高的项目。彩色成本条便于比较各项目的相对成本；所有成本均依据可用模型价格估算。

## 模型视图

打开模型视图，查看各模型的用量与预估成本。模型名称取自本地 Codex 日志。成本估算依赖可用价格；未知模型的预估成本默认为零。

对比不同视图时，请使用相同日期范围。项目和模型明细可以解释看板总量，会话视图则能定位到具体工作。
