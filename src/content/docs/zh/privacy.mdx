## 首次使用需要提交什么

无需注册 Codex Usage Desktop 账号，也无需向应用填写或保存 OpenAI、LiteLLM API Key。应用在本机读取 Codex 主目录下已有的会话日志，并使用本机已有的 Codex 登录状态查询实时额度。

## 哪些内容保留在电脑上

源日志在本地读取，应用不会上传、分享或修改这些会话日志。汇总用量保存在操作系统应用数据目录中的 SQLite 缓存中，便于读取和展示统计。

会话可能包含提示词、源代码、命令、工作目录等敏感内容。能在应用中查看它们，不代表这些内容已被上传。

## 应用何时联网

- **实时额度**：使用已有的本机 Codex 身份验证直接向 ChatGPT 请求当前账户限制，请求不附带会话日志。
- **模型价格**：获取公开定价并在本地缓存，供成本估算与价格目录使用。
- **其他资源**：获取公开字体文件、额度预测和更新信息。

这些请求不包含会话日志或使用分析数据。“本地读取日志”也不意味着所有功能都不需要网络。额度查询和更新等功能仍需连接相应服务，价格目录离线时可能只有有限的内置数据。

## 截图、导出和反馈前的检查

1. 截图只保留需要解释的区域，遮盖账户、项目名、绝对路径和会话标题。
2. 展开活动后，再检查提示词、代码、命令、搜索内容和文件名。
3. 导出文件逐页或逐表检查，不要只查看第一页。
4. 提交问题时仅提供排查所需的内容，不要附上完整日志、登录凭据或密钥。

应用本身不会上传会话日志，但你主动分享的截图、文件和问题报告由你决定公开范围。更多细节可查看[源代码](https://github.com/itvincent-git/codex-usage-desktop)，遇到问题请参考[故障排查](/zh/docs/troubleshooting/)。
