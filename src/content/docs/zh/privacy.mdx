## 本地会话数据

应用在本地读取 Codex 主目录中的源文件，不会上传、分享或修改会话日志。汇总用量存于操作系统应用数据目录中的 SQLite 缓存。无需在应用中输入或保存 OpenAI 或 LiteLLM API Key。

## 网络请求

实时额度使用本机已有的 Codex 身份验证，直接向 ChatGPT 请求；请求不附带会话日志。应用还会获取公开字体文件、模型价格、额度预测和更新信息。价格会在本地缓存。这些请求不包含会话日志或使用分析数据。

会话可能包含敏感提示词、代码和命令。请谨慎处理本地数据和自行导出的文件。[源代码](https://github.com/itvincent-git/codex-usage-desktop)可供检查。
