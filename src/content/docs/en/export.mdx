## Export a range

Choose the date range you want on the dashboard, then use the export action. You can save the selected range as an Excel `.xlsx` workbook or a Markdown `.md` file.

Review the date range and values before sharing. Cost figures are estimates based on available model pricing, and unknown models default to zero estimated cost. Exports may reveal project names and usage patterns even when they do not include full session logs.

For deeper investigation, use the Project, Model, and Sessions views before exporting.
