## Project view

Open Project to compare token use and estimated cost by project directory. Each row brings together daily token bars, a cost trend line, and the non-cached input, cached input, and output breakdown.

Choose a date range, then sort by total tokens or cost to find the projects driving your usage. Colored cost bars make relative costs easy to compare; all costs are estimates based on available model pricing.

## Model view

Open Model to see which models contributed to usage and estimated cost. The figures use model names found in local Codex logs. Cost estimates depend on available pricing; an unknown model defaults to zero estimated cost.

Use the same date range across views when comparing totals. A project or model breakdown helps explain the dashboard total, while the Sessions view shows the individual work behind it.
