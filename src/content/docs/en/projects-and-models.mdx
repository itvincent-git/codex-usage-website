## Project view

Open Project to compare token use and estimated cost by workspace. Select a project for its token composition, trend, and related sessions.

## Model view

Open Model to see which models contributed to usage and estimated cost. The figures use model names found in local Codex logs. Cost estimates depend on available pricing; an unknown model defaults to zero estimated cost.

Use the same date range across views when comparing totals. A project or model breakdown helps explain the dashboard total, while the Sessions view shows the individual work behind it.
