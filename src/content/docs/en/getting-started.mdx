## Install

Download the Windows x64 installer, Apple Silicon DMG, or Intel Mac DMG from the [download page](/download/). Windows uses a current-user installer. On macOS, open the DMG and move the app to Applications.

## Your first scan

1. Use Codex CLI so that session logs exist in your local Codex home directory.
2. Open Codex Usage Desktop. It discovers the logs and builds a local SQLite index.
3. Choose a date range, then open the Dashboard, Model, Project, Daily, Monthly, or Sessions views.

No separate account, API key, analytics server, or database setup is needed. Live limits require an authenticated local Codex CLI session. If necessary, run `codex auth login` and refresh the app.

For release notes and development or contribution instructions, visit the [GitHub project](https://github.com/itvincent-git/codex-usage-desktop).
