## 這個應用程式能幫你做什麼

Codex Usage Desktop 把本機已有的 Codex 工作階段記錄整理成用量儀表板。你可以用它回答三個問題：最近用了多少 Token、帳戶還剩多少額度、哪些專案和工作階段消耗最多。

它是檢視和分析用量的桌面應用程式。開始前，請先安裝並使用 Codex CLI，讓電腦上有可讀取的工作階段記錄。無需為本應用程式另建帳號、填寫 API Key、部署伺服器或設定資料庫。

## 第一步：安裝適合你電腦的版本

前往[下載頁](/zh-tw/download/)，按裝置選擇安裝檔：

- **Windows 10/11 x64**：下載並執行安裝程式，按提示完成目前使用者安裝。
- **Apple 晶片 Mac**：選擇 Apple Silicon DMG。
- **Intel Mac**：選擇 Intel Mac DMG。在 Mac 的「關於本機」中可以確認晶片類型。

macOS 使用者開啟 DMG 後，將應用程式拖入「應用程式」，再從那裡啟動。遇到系統攔截時，按[疑難排解](/zh-tw/docs/troubleshooting/)中的安裝提示處理。

## 第二步：讀取你的第一次用量

1. 在平時使用的終端機裡開啟 Codex CLI，完成一次正常的互動，確保已有工作階段記錄。
2. 開啟 Codex Usage Desktop，等待首次掃描完成。應用程式會在本機建立統計索引，記錄較多時請等掃描結束再看總量。
3. 在儀表板選擇覆蓋剛才工作階段的日期範圍，例如最近 7 天。
4. 確認儀表板出現 Token 數值，再開啟「工作階段」，找到剛才的記錄。

macOS 通常從 `~/.codex` 讀取；Windows 的原生目錄與 WSL 發現規則見 [Windows 與 WSL](/zh-tw/docs/windows-wsl/)。如果沒有記錄，先擴大日期範圍，再使用「重新掃描本機記錄」。

## 第三步：連線即時額度

Token 統計來自本機記錄，即時額度來自帳戶服務，兩者可以分別成功或失敗。如果 Token 已出現，但額度卡片不可用，請確認本機 Codex CLI 已登入。必要時在終端機執行：

```sh
codex login
```

完成登入後，返回應用程式查詢額度。應用程式沿用本機已有的登入狀態，無需再貼上金鑰。關於查詢與啟動視窗的區別，請閱讀[額度與限制](/zh-tw/docs/quota/)。

## 第一次使用，建議這樣瀏覽

1. **看總量**：在[儀表板](/zh-tw/docs/dashboard/)認識輸入、快取、輸出和預估成本。
2. **看還能用多少**：在[額度指南](/zh-tw/docs/quota/)瞭解剩餘百分比與重設倒數計時。
3. **找出來源**：在[專案與模型](/zh-tw/docs/projects-and-models/)比較用量，再開啟[工作階段詳細資料](/zh-tw/docs/sessions/)檢視具體活動。
4. **儲存結果**：需要週報或進一步計算時，[匯出 Excel 或 Markdown](/zh-tw/docs/export/)。

這些統計只覆蓋本機能夠讀取的記錄。其他電腦上的工作不會自動合併。記錄的儲存與聯網範圍見[隱私說明](/zh-tw/docs/privacy/)。
