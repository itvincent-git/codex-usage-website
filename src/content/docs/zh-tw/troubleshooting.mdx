## 先判斷是哪一類問題

Token 統計來自本機記錄，即時額度需要帳戶身分驗證和網路，預估成本還依賴模型價格。因此「有工作階段但沒有額度」或「有 Token 但成本為零」可以分別排查。

## 看不到工作階段或總量偏少

1. 在平時使用 Codex 的環境裡完成一次互動，確認已經產生 JSONL 記錄。
2. 清空工作階段搜尋，擴大日期範圍，避免記錄只是被篩掉。
3. 使用「重新掃描本機記錄」，等掃描完成後再次檢視。
4. 檢查是否設定了 `CODEX_HOME`，它會覆蓋自動發現。變數調整後需要重新啟動應用程式。
5. Windows 使用者核對[原生與 WSL 的發現順序](/zh-tw/docs/windows-wsl/)。兩邊的資料不會合併；其他電腦上的記錄也不會自動出現。

如果只是午夜附近的記錄落在前一天或後一天，請檢查系統時區與 `CODEX_USAGE_TIMEZONE`，詳見[進階設定](/zh-tw/docs/advanced-settings/)。不要透過修改或刪除原始記錄來修正顯示問題。

## 工作階段有記錄，但即時額度不可用

1. 確認網路可用。
2. 確認應用程式所使用的 Codex CLI 已登入；必要時在相同環境執行 `codex login`。
3. 返回應用程式重新查詢額度。
4. 若使用了自訂 CLI 安裝位置，檢查 `CODEX_CLI_PATH`，修改後重新啟動。

查詢額度本身不消耗模型額度；無需透過「啟動額度視窗」排查查詢失敗。

## 成本為零，或不同頁面數值不同

模型沒有可用定價時，預估成本預設為零。到「模型 → 價格目錄」搜尋模型並重新整理價格；零估算不能證明使用免費。

比較頁面前，核對日期範圍、時區和篩選條件。輸入包含快取，不能重複相加；工作階段額度消耗估算也不能與帳戶目前剩餘百分比直接比較。請參閱[儀表板指標](/zh-tw/docs/dashboard/)和[工作階段指南](/zh-tw/docs/sessions/)。

## 安裝時被系統提示攔截

Windows 安裝檔尚未進行 Authenticode 簽章，SmartScreen 可能警告。先確認安裝檔來自專案 GitHub Release。macOS 若被 Gatekeeper 阻止首次啟動，在「系統設定 → 隱私與安全性」中允許應用程式，不要關閉或繞過 Gatekeeper。

## 仍然無法解決時，如何回報

檢視[專案 Issues](https://github.com/itvincent-git/codex-usage-desktop/issues)，已有相同問題時可參考其中的處理方式。提交新報告時，提供：

- 作業系統、晶片架構和應用程式版本。
- Codex 執行於原生環境還是 WSL，是否自訂路徑或時區。
- 重現步驟、預期結果和實際結果，以及重新掃描後是否仍然出現。
- 已遮蓋私人資訊的錯誤提示或必要診斷內容。

不要公開帳戶、金鑰、絕對路徑、私人專案名或完整工作階段記錄。需要截圖時，先按[隱私指南](/zh-tw/docs/privacy/)檢查再分享。
