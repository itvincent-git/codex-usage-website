## 想找用量來源，從這裡開始

儀表板告訴你總共用了多少，「專案」回答「用在哪項工作上」，「模型」回答「由哪些模型產生」。先選擇要調查的日期範圍，再比較，避免把不同時間段的結果放在一起。

## 按專案定位工作

1. 開啟「專案」，檢視專案名稱與目錄。名稱相近時，用路徑區分不同工作目錄。
2. 先按總 Token 降序排序，找到用量最多的專案；想了解成本來源時，改按成本排序。
3. 檢視該行的每日 Token 柱狀圖、成本趨勢線與 Token 構成，判斷是某一天集中使用還是持續產生用量。
4. 點選專案開啟詳細資料，在所選範圍內檢視分析和按天分組的工作階段；展開日期，搜尋並開啟具體工作階段。

還可以按專案名稱、最近使用時間、輸入、快取或輸出排序，並切換升序與降序。彩色成本條用於比較各專案的相對大小，不能當成帳戶額度警報。

Token 構成中的未快取輸入、快取輸入和輸出互不重複。若檢視的是「輸入（含快取）」，就不要再疊加快取數值。

## 按模型比較用量和價格

開啟「模型」的「用量分析」，先看活躍模型、Token 佔比與成本佔比，再檢視模型比較表。可以按總 Token、預估成本或有效單價排序。

- **標準單價**：每百萬未快取輸入、快取輸入或輸出 Token 的參考價格，三類單價應分別閱讀。
- **有效單價**：該模型預估成本除以總 Token，再換算成每百萬 Token，反映目前輸入、快取、輸出構成下的綜合結果。
- **預估成本**：由模型定價和實際用量構成共同決定。因此 Token 最多的模型不一定成本最高。

模型名來自本機記錄。沒有可用定價的模型預估成本預設為零；零成本不能證明這部分使用免費。

## 模型額度消耗估算怎麼看

資料足夠時，模型頁還會估算所選時段內各模型消耗的 5 小時與每週額度，並給出每百萬 Token 的消耗作為比較參考。

估算依據單一模型工作階段中的歷史額度快照。快照為整數百分比，介面會提供誤差範圍；同時執行的其他工作階段也可能影響歸因。「暫無可歸因快照」表示證據不足，不表示該模型不消耗額度。這個區域不能替代[即時額度](/zh-tw/docs/quota/)。

## 查價格目錄

切換到「價格目錄」，按模型或供應商搜尋，必要時使用供應商篩選和「重新整理價格」。目錄的單位是美元 / 百萬 Token，收錄的模型不一定是你使用過的模型。離線時可能只顯示有限的內建價格。

定位到主要專案後，繼續用[工作階段指南](/zh-tw/docs/sessions/)追查具體任務；需要保留比較結果時，可[匯出所選範圍](/zh-tw/docs/export/)。
