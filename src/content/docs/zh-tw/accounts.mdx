## 開啟帳號頁面

在 Codex Usage Desktop 的側邊欄選擇 **帳號**。你可以儲存多個 ChatGPT 帳號和 API Key 設定。查看、新增或重新整理帳號時，Codex 會繼續使用目前的登入。瀏覽器和裝置碼登入都需要在所選環境中安裝官方 Codex CLI。

## 新增 ChatGPT 帳號

1. 如果本機 Codex 已登入，選擇**新增目前 Codex 帳號**儲存該登入。若使用 Codex 內建 OpenAI 供應商，且憑證儲存在檔案中，也可匯入 API Key 登入。
2. 要新增其他帳號，選擇 **新增帳號**（第一次使用時可能顯示 **新增其他帳號**），再選 **在瀏覽器中登入**。若 Codex 尚未登入，也可以直接從空白的帳號頁面開始登入。
3. 在瀏覽器確認要使用的 ChatGPT 帳號與工作區，完成授權後回到應用程式。帳號會自動儲存。

也可以選擇 **使用裝置碼登入**，開啟應用程式提供的授權頁面並輸入裝置碼。關閉登入視窗後，可以選擇 **繼續登入** 返回。若要結束這次授權，請選擇 **取消登入**。

## 新增 API Key

1. 在尚未儲存帳號的帳號頁面，或在**新增帳號**對話方塊中，選擇**新增 API Key**。
2. 輸入易於辨識的名稱和金鑰。使用 OpenAI 官方端點時，Base URL 可留空，預設為 `https://api.openai.com/v1`。第三方服務必須支援 Responses API。請填寫完整的 API 根網址，例如 `https://gateway.example.com/v1`。
3. 選擇 **儲存 API Key**。要讓 Codex 使用這組設定時，再依照下方的步驟切換。

API Key 卡片會顯示名稱和 Base URL。API 用量與帳單請向供應商查詢。歷史 Token 和預估成本依所選 Codex 目錄中的工作階段統計，可能包含多個帳號的用量。

## 查看並重新整理額度

依方案而定，ChatGPT 帳號卡片會顯示 5 小時與每週額度，或每月額度。資料可用時，也會顯示重設時間、訂閱狀態、餘額及重設額度。應用程式會在背景重新整理，也可以選擇卡片上的 **重新整理**，或用 **全部重新整理** 更新所有 ChatGPT 帳號。

重新整理失敗時，卡片會標記上次成功取得的資料。展開 **資料詳情** 即可查看更新時間和錯誤。如果出現登入提示，選擇 **重新登入**，並使用相同的 ChatGPT 帳號和工作區。各項數值的意義請參閱[額度與限制](/zh-tw/docs/quota/)。

## 切換帳號並重新啟動 Codex

1. 在要使用的帳號卡片上選擇 **切換 Codex 登入**。切換會寫入所選 Codex 環境的登入設定。切換至 API Key 時會一併設定 API 端點。切回 ChatGPT 時，會清除 API 供應商與端點設定。
2. 卡片顯示 **Codex 已設定** 後，重新啟動 Codex 桌面用戶端或 IDE，讓它載入新的登入。
3. 若使用 Codex CLI，請結束目前的工作階段，再執行 `codex --no-daemon`。也可以執行 `codex app-server daemon stop` 停止背景伺服器，再照常啟動 Codex CLI。

如果無法切換，請先查看帳號頁面的提示。切換需要使用檔案儲存憑證。Codex 設定中的 `cli_auth_credentials_store` 可以省略或設為 `"file"`。系統鑰匙圈與組織管理政策可能阻止寫入。如果應用程式提示設定有變更，請先確認所選環境與設定再重試。WSL 需要在所選發行版安裝 Python 3.11 或更新版本，授權登入還需要 `setsid`。環境選擇方式請參閱 [Windows 與 WSL](/zh-tw/docs/windows-wsl/)。

## 移除帳號並保護憑證

從帳號卡片的 **更多** 選單選擇 **移除**，即可刪除本應用程式儲存的憑證與狀態快取。若移除目前帳號，Codex 會繼續使用該登入，直到你主動切換或登出。

已儲存的 ChatGPT 憑證和 API Key 以純文字保存在本機，並以檔案權限限制存取。分享螢幕截圖時請遮蔽帳號與工作區資訊，分享備份或回報問題時請排除憑證檔案和金鑰。詳見[隱私權與網路存取](/zh-tw/docs/privacy/)。
