## 什麼時候使用匯出

需要做週報、比較不同時間段或在表格中繼續計算時，可以把所選範圍的統計儲存為檔案。匯出面向用量彙總；檢視某條命令或提示文字應使用[工作階段時間軸](/zh-tw/docs/sessions/)。

## 從選定範圍到儲存檔案

1. 在儀表板選擇需要的日期範圍。週報可以使用自訂日期，明確選好起止日期。
2. 確認掃描完成，並核對總 Token 與預估成本是否符合要記錄的範圍。
3. 使用「資料匯出」，選擇 Excel `.xlsx` 或 Markdown `.md`。
4. 在儲存對話方塊中選擇檔案位置並儲存，再開啟檔案核對日期範圍、時區和總量。

## 應該選擇哪種格式

- **Excel**：適合篩選、計算和製作圖表。工作簿包含 Summary、Daily、Models、Projects 四個工作表，分別提供摘要、每日、模型和專案統計。
- **Markdown**：適合在筆記或報告中閱讀、引用彙總資料。分享前可以先用文字編輯器檢查和刪去敏感內容。

匯出使用選定範圍的資料。若你需要另一週的結果，請切換日期後重新匯出，不要只修改檔名。

## 如何理解匯出的成本

成本以可用模型價格估算，不是訂閱帳單。未知模型的估算預設為零。比較兩個匯出檔案時，先確認日期範圍、時區和價格條件，避免把統計口徑變化當成用量變化。

## 分享之前檢查什麼

匯出檔案仍可能包含專案名稱、目錄路徑和使用習慣。請檢查每個工作表或整份 Markdown，遮蓋私人專案、路徑、帳戶資訊等細節後再分享。不要因為檔案沒有完整工作階段內容，就認為可以直接公開。

如果發現某個專案的數值異常，回到[專案與模型](/zh-tw/docs/projects-and-models/)定位，再檢視相關工作階段。
