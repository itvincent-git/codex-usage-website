## 先分清：已用多少與還能用多少

儀表板上的 Token 總量回答「本機記錄了多少用量」；額度卡片回答「帳戶現在還能用多少」。額度來自 ChatGPT 的即時帳戶狀態，使用本機已有的 Codex 登入資訊查詢。

## 第一次查詢額度

1. 確認平時使用的 Codex CLI 已登入；必要時執行 `codex login`。
2. 開啟儀表板的額度卡片，使用「查詢額度」。即時查詢需要網路連線。
3. 分別檢視 5 小時限制與每週或每月限制的剩餘額度、重設時間和倒數計時。具體顯示取決於帳戶返回的資料。

兩個視窗應分別閱讀。即使 5 小時額度充足，較長週期的額度也可能接近上限。倒數計時對應各自視窗，不代表所有額度會一起重設。

## 如何讀懂百分比和倒數計時

- **剩餘額度**：目前視窗還可以使用的比例。它是額度比例，不是固定的可用 Token 數。
- **重設時間與倒數計時**：該視窗的重設時刻，以及距離該時刻還有多久。
- **重設額度與預測**：只有底層資料可用時才會顯示。預測可能變化，不能當成保證。

> 虛構範例：5 小時剩餘 70%、每週剩餘 20%，表示短週期餘量較多，但長週期已經使用較多。不能把兩者相加，也不能用 70% 乘本機 Token 總量來推算還能用多少。

## 「查詢額度」和「啟動額度視窗」有何區別

**查詢額度**唯讀取伺服器上的目前狀態，不會啟動或延長 5 小時視窗，也不會消耗模型額度。日常只想看餘量時，使用這個操作即可。

**啟動額度視窗**會傳送一次最小 Codex 請求，消耗少量 5 小時及每週額度，並在傳送前請你確認。它只對符合條件的訂閱開放，且要等現有 5 小時視窗結束後才能使用；視窗仍在生效時不可用。只有你希望主動開始一個新視窗時才需要它。

## 工作時隨時檢視

在「設定」中找到選單列或系統匣選項，選擇要顯示的額度文字和倒數計時單位。macOS 使用者可從選單列檢視，Windows 使用者可從系統匣檢視，無需一直開啟主視窗。

想了解公告、歷史變化或重設額度的到期時間，繼續閱讀[額度重設](/zh-tw/docs/resets/)。

## 查詢失敗或與工作階段不一致

先檢查網路和 CLI 登入狀態，再查詢一次。工作階段清單中的百分比表示**該工作階段預估消耗的額度**；這裡顯示的是**帳戶目前剩餘的額度**。兩者含義不同，更新時間也可能不同。更多排查方法見[疑難排解](/zh-tw/docs/troubleshooting/)。
