## 什麼時候看這個頁面

想知道「今天用了多少」「最近用量是否增加」或「哪個時間段突然升高」，先看儀表板。它彙總所選日期範圍內的本機記錄，再讓你透過每日、每月、專案、模型和工作階段檢視繼續追查。

## 先選時間，再讀數值

1. 在日期選擇器中選擇最近 7 天、30 天等預設範圍。
2. 要檢視某一週或某段工作，選擇自訂日期，選好開始和結束日期後套用。
3. 先讀總 Token 與預估成本，再看輸入、快取和輸出的構成。
4. 對比專案、模型或匯出資料時，使用相同日期範圍。

## 各項指標是什麼意思

- **Token**：模型處理文字的計量單位，不能直接當成字數、訊息條數或任務數量。
- **輸入 Token**：傳送給模型處理的上下文，包含其中命中快取的部分。
- **快取輸入 Token**：輸入中被重複使用的部分，已經計入輸入，不能再加一次。
- **輸出 Token**：模型生成內容所使用的 Token。
- **快取命中率**：快取輸入佔輸入總量的比例。它描述輸入的重複使用程度，不表示帳戶還剩多少額度。
- **預估成本**：按可用模型價格計算的美元參考值，不是訂閱帳單，也不是額外收費通知。
- **日均用量**：將所選範圍總量除以範圍內的天數，包含無活動日期，展示每日平均 Token 和預估成本。

> 虛構範例：輸入 100,000 Token，其中快取 60,000，輸出 20,000。總量為 120,000；未快取輸入為 40,000，快取命中率為 60%。不能把快取再加到總量中。

## 用每日和每月檢視找出峰值

**每日**適合查「哪天用得最多」。你可以按日期、總 Token、輸入、快取、輸出或成本排序，點選有活動的日期檢視當天工作階段。連續無活動日期可能摺疊顯示。

**每月**適合觀察長期變化，再回到每日檢視縮小排查範圍。比較柱狀構成時，未快取輸入、快取輸入和輸出是互不重複的三部分。

例如本週總量明顯增加，可以先在每日檢視找到高峰，再去[專案與模型](/zh-tw/docs/projects-and-models/)確認主要來源，最後在[工作階段](/zh-tw/docs/sessions/)中檢視當天做了什麼。

## 為什麼儀表板和額度數字不一致

儀表板計算的是本機記錄中的用量，即時額度讀取的是帳戶目前狀態。其他裝置上的使用、記錄寫入和重新整理時間都可能使兩者不同，不能用 Token 總量直接換算剩餘額度。

最新記錄缺失時，確認日期範圍後使用「重新掃描本機記錄」。成本為零也可能是模型沒有可用定價，詳見[模型與價格](/zh-tw/docs/projects-and-models/)。
