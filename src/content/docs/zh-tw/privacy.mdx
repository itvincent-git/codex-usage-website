## 首次使用需要提交什麼

無需註冊 Codex Usage Desktop 帳號，也無需向應用程式填寫或儲存 OpenAI、LiteLLM API Key。應用程式在本機讀取 Codex 主目錄下已有的工作階段記錄，並使用本機已有的 Codex 登入狀態查詢即時額度。

## 哪些內容保留在電腦上

原始記錄在本機讀取，應用程式不會上傳、分享或修改這些工作階段記錄。彙總用量儲存在作業系統應用程式資料目錄中的 SQLite 快取中，便於讀取和展示統計。

工作階段可能包含提示文字、原始碼、命令、工作目錄等敏感內容。能在應用程式中檢視它們，不代表這些內容已被上傳。

## 應用程式何時聯網

- **即時額度**：使用已有的本機 Codex 身分驗證直接向 ChatGPT 請求目前帳戶限制，請求不附帶工作階段記錄。
- **模型價格**：取得公開定價並在本機快取，供成本估算與價格目錄使用。
- **其他資源**：取得公開字型檔案、額度預測和更新資訊。

這些請求不包含工作階段記錄或使用分析資料。「本機讀取記錄」也不意味著所有功能都不需要網路。額度查詢和更新等功能仍需連線相應服務，價格目錄離線時可能只有有限的內建資料。

## 截圖、匯出和回報前的檢查

1. 截圖只保留需要解釋的區域，遮蓋帳戶、專案名、絕對路徑和工作階段標題。
2. 展開活動後，再檢查提示文字、程式碼、命令、搜尋內容和檔名。
3. 匯出檔案逐頁或逐表檢查，不要只檢視第一頁。
4. 提交問題時僅提供排查所需的內容，不要附上完整記錄、登入憑證或金鑰。

應用程式本身不會上傳工作階段記錄，但你主動分享的截圖、檔案和問題報告由你決定公開範圍。更多細節可檢視[原始碼](https://github.com/itvincent-git/codex-usage-desktop)，遇到問題請參考[疑難排解](/zh-tw/docs/troubleshooting/)。
