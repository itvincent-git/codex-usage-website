## 首次使用需要提交什麼

應用程式在本機讀取 Codex 工作階段記錄，也可以沿用既有的 ChatGPT 登入查詢即時額度。查看本機用量無需另外註冊 Codex Usage Desktop 帳號或填寫 API Key。

如果透過[帳號管理](/zh-tw/docs/accounts/)儲存 ChatGPT 帳號或 API Key，應用程式會將憑證以純文字保存在本機，並透過檔案權限限制存取。請從共享備份及問題回報中排除憑證檔案。

## 哪些內容保留在電腦上

原始記錄在本機讀取，應用程式不會上傳、分享或修改這些工作階段記錄。彙總用量儲存在作業系統應用程式資料目錄中的 SQLite 快取中，便於讀取和展示統計。

工作階段可能包含提示文字、原始碼、命令、工作目錄等敏感內容。能在應用程式中檢視它們，不代表這些內容已被上傳。

## 應用程式何時聯網

- **即時額度與帳號狀態**：使用對應帳號的本機憑證直接向 ChatGPT 查詢。帳號頁面也會在背景重新整理已儲存的 ChatGPT 帳號。請求含有必要的身分驗證資料，會省略工作階段記錄。
- **模型價格**：取得公開定價並在本機快取，供成本估算與價格目錄使用。
- **工作階段 credits 查詢**預設關閉。開啟後，應用程式使用你的 ChatGPT 登入憑證，直接將工作階段 ID 傳送給 ChatGPT，並依帳號在本機快取傳回的扣除量。工作階段內容留在本機。
- **其他資源**包括公開字型檔案，以及 codex-reset.com 提供的重設公告與預測。

即時額度查詢與更新檢查需要網路連線。離線時，價格目錄可能只包含有限的內建資料。

## 截圖、匯出和回報前的檢查

1. 截圖只保留需要解釋的區域，遮蓋帳戶、專案名、絕對路徑和工作階段標題。
2. 展開活動後，再檢查提示文字、程式碼、命令、搜尋內容和檔名。
3. 匯出檔案逐頁或逐表檢查，不要只檢視第一頁。
4. 提交問題時僅提供排查所需的內容，不要附上完整記錄、登入憑證或金鑰。

應用程式本身不會上傳工作階段記錄，但你主動分享的截圖、檔案和問題報告由你決定公開範圍。更多細節可檢視[原始碼](https://github.com/itvincent-git/codex-usage-desktop)，遇到問題請參考[疑難排解](/zh-tw/docs/troubleshooting/)。
